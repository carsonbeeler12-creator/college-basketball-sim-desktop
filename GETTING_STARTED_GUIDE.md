# Getting Started with College Basketball Dynasty

Welcome to College Basketball Dynasty! This guide will help you download, install, and start your first dynasty.

---

## 📥 Download & Installation

### Windows
1. Download **College-Basketball-Dynasty-0.9.7-beta-Windows-Portable.zip**
2. Right-click the downloaded file → **Extract All**
3. Open the extracted folder
4. Double-click **College Basketball Dynasty (BETA).exe**
5. If Windows shows a security warning, click **"More info"** → **"Run anyway"**

### Linux
1. Download **College Basketball Dynasty (BETA)-Linux-0.9.7-beta.tar.gz**
2. Extract: `tar -xzf "College Basketball Dynasty (BETA)-Linux-0.9.7-beta.tar.gz"`
3. Navigate to the extracted folder
4. Run: `./college-basketball-dynasty`
5. If you get a permission error: `chmod +x college-basketball-dynasty` then try again

### macOS
1. Download the `.dmg` file
2. Double-click to open
3. Drag **College Basketball Dynasty** to your Applications folder
4. If macOS blocks it: **System Preferences** → **Security & Privacy** → Click **"Open Anyway"**

## 🎮 First Time Setup

### Creating Your Dynasty

When you launch the app for the first time:

1. **Click "New Dynasty"**
2. **Enter your coach name** (this is you!)
3. **Select a team** from 100+ college basketball programs
4. **Choose your coaching scheme:**
   - **Pass-Heavy**: Guards develop faster, great for perimeter-focused teams
   - **Post-Heavy**: Centers dominate, perfect for paint-oriented play
   - **Balanced**: All positions develop equally, maximum flexibility
5. **Click "Start Dynasty"**

## 📊 Understanding Your Team

### Player Ratings
Each player has ratings for:
- **Shooting**: Three-point and mid-range accuracy
- **Inside Scoring**: Layups, dunks, post moves
- **Defense**: On-ball defense and rebounding
- **Athleticism**: Speed, jumping, stamina
- **IQ**: Decision-making and positioning

### Development System
- Players develop based on **playing time** and your **coaching scheme**
- Guards develop faster in Pass-Heavy schemes
- Centers develop faster in Post-Heavy schemes
- Balanced schemes give equal development to all positions

## 🎯 Recruiting

### How Recruiting Works
1. Go to the **Recruiting** tab
2. View available recruits and their ratings
3. Higher-rated recruits are harder to sign
4. Your team's success improves recruiting appeal
5. Recruits prefer teams that match their position style

### Tips
- Focus on positions that fit your scheme
- Balance star recruits with solid role players
- Check recruit potential (some improve more than others)
- Don't ignore development—young players can become stars

## 💾 Saving Your Dynasty

**Auto-Save:**
- The game saves automatically after each action
- Your dynasty is stored locally on your computer
- Find it in: `%AppData%/college-basketball-dynasty/dynasties/` (Windows)

**Manual Save:**
- Click the **Save** button anytime
- Multiple dynasties can be saved

## 🐛 Troubleshooting

### Game Won't Launch (Windows)
- Make sure you **extracted** the zip file (don't run from inside the zip)
- Try running as Administrator
- Check Windows Defender didn't block it

### Performance Issues
- Close other apps to free up RAM
- Reduce simulation speed if games lag
- Update graphics drivers

### Lost Dynasty
- Check `%AppData%/college-basketball-dynasty/dynasties/`
- Dynasties are saved as `.json` files
- You can back these up manually
